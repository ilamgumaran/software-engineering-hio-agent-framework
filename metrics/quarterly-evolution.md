# Quarterly Evolution Review

Template for the quarterly evolution review -- the most comprehensive assessment in the measurement cadence. This is a half-day session (3-4 hours) that examines the full transformation arc: purpose, structure, people, AI, metrics, and plan.

The quarterly review is where the transformation plan gets revised based on evidence. Everything before this point is data collection. This is where data becomes decisions.
