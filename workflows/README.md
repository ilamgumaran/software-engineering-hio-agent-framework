# Harmonized Sprint Workflows

## The Harmonized Sprint Model

The Harmonized Sprint replaces standard scrum ceremonies with a model built around outcomes, energy, and emergence. Cognitive units (teams of 6-8 including AI agents) run 2-week sprints using HIO ceremonies instead of traditional scrum events.

### Key Differences from Scrum

| Dimension | Standard Scrum | Harmonized Sprint |
|-----------|---------------|-------------------|
| Planning | Sprint Planning (estimate stories) | [Sprint Kickoff](sprint-kickoff.md) (AI pre-analysis first, then human framing) |
| Daily Sync | Daily Standup (status updates) | [Daily Harmony Check](daily-harmony-check.md) (energy flow, not status) |
| Review | Sprint Review (demo features) | [Sprint Outcome Review](sprint-outcome-review.md) (outcomes achieved, not features shipped) |
| Retrospective | Sprint Retrospective (process improvement) | [Harmonization Retrospective](harmonization-retrospective.md) (emergence, fulfillment, growth) |
| Focus Time | No equivalent | [Deep Work Blocks](deep-work-collaboration.md) (4 hours/day protected) |
| Innovation | No equivalent | [Exploration Time](exploration-time.md) (3-4 hours/week) |

## Sprint Rhythm

A two-week harmonized sprint follows this weekly rhythm:

### Week 1

| Day | Morning | Afternoon |
|-----|---------|-----------|
| Monday | Sprint Kickoff (2 hrs) | Deep Work (2 hrs) |
| Tue-Thu | Deep Work (4 hrs) | Daily Harmony Check (15 min) + Collaboration Windows (2 hrs) |
| Friday | Deep Work (4 hrs) | Exploration Time (2 hrs) |

### Week 2

| Day | Morning | Afternoon |
|-----|---------|-----------|
| Monday | Mid-Sprint Check (30 min) + Deep Work | Collaboration Windows (2 hrs) |
| Tue-Thu | Deep Work (4 hrs) | Daily Harmony Check (15 min) + Collaboration Windows (2 hrs) |
| Friday | Sprint Outcome Review (1 hr) | Harmonization Retrospective (1 hr) + Exploration Time (1 hr) |

Daily constants: Harmony Check (15 min), Deep Work (4 hrs), Collaboration Windows (2 hrs).

Weekly: 3-4 hours exploration time distributed across the week.

## How Workflows Connect

The workflows form an interconnected system. The Sprint Kickoff produces outcomes that the Daily Harmony Check tracks energy around. Deep Work and Collaboration provide the daily structure where actual progress happens. The Sprint Outcome Review evaluates whether outcomes were achieved, and the Harmonization Retrospective examines how the unit is evolving. Exploration Time feeds new ideas back into future Sprint Kickoffs.

```
Sprint Kickoff --> Daily Harmony Check --> Deep Work & Collaboration
     ^                                            |
     |                                            v
Exploration Time <-- Harmonization Retro <-- Sprint Outcome Review
```

AI agents participate throughout: doing pre-analysis before ceremonies, working asynchronously during deep work, and providing metrics and documentation at review points. The human cognitive functions guide framing, decision-making, energy sensing, and growth.

---

## Key Principles

- **AI does pre-work asynchronously** before human engagement. Humans never start from a blank page.
- **Outcomes, not outputs.** Success is measured by what changed, not what shipped.
- **Energy flow matters** as much as task completion. Low energy is a signal, not a weakness.
- **Emergence is celebrated and documented.** Unexpected value from human-AI collaboration is the goal.
- **Thinking time is work time.** Deep work blocks are non-negotiable.
- **No fixed roles for tasks.** Members claim work based on interest and growth, not assignment.
- **AI outputs are starting points.** Human judgment reframes, challenges, and enriches AI analysis.
- **Measure fulfillment, not velocity.** If the team is not growing, the process is failing.
