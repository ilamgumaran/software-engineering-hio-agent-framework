# Phase 0: Seed (Weeks 1-3)

## Strategic Intent

Plant the measurement infrastructure and identify the pioneers who will form the first cognitive unit. Phase 0 is about creating the conditions for transformation without yet transforming anything visible. The org continues operating normally while the foundation is laid beneath it.

---

## Timeline

| Week | Focus | Key Activities |
|------|-------|---------------|
| **Week 1** | Measurement | Deploy DORA metric collection, run first fulfillment survey, capture baseline |
| **Week 2** | Tooling + Profiles | Provision AI tools, begin cognitive profiling workshops |
| **Week 3** | Selection + Configuration | Select pioneers, configure agents, prepare for Phase 1 launch |

---

## Key Deliverables

| Deliverable | Definition of Done |
|-------------|-------------------|
| **Measurement baseline** | All 3 metric layers documented in `org/measurement-baseline.md` |
| **AI tool access** | Claude Code and GitHub Copilot accessible to all pioneers |
| **Cognitive profiles** | Each pioneer has completed `org/cognitive-profiles.md` template |
| **Pioneer cohort** | 5-6 volunteers identified and committed |
| **Agent guardrails** | Policies documented in `org/policies.md` and approved by security |
| **First unit outcome** | One-sentence outcome statement for the first cognitive unit |

---

## Exit Criteria

Phase 0 is complete when:

1. The measurement baseline is captured and stored
2. At least one DORA metric is collecting automatically
3. Pioneers are selected and have completed cognitive profiling
4. AI tools are provisioned and security-approved
5. Leadership has approved the Phase 1 plan

**If exit criteria are not met by Week 3:** Extend Phase 0 by 1 week. Do not begin Phase 1 without reliable measurement -- you cannot prove the transformation works without a baseline.

---

## Risks

| Risk | Mitigation |
|------|-----------|
| Security review delays AI tool access | Start security review in Week 1, provide sandbox access while review is pending |
| Not enough volunteers | Share the vision broadly, but do not pressure -- even 4 committed pioneers is enough |
| Measurement tooling gaps | Accept manual measurement for Phase 0; automate during Phase 1 |

See `transformation/phase-0-seed.md` for full operational detail and `plan/03-implementation-guide.md` for step-by-step instructions.
