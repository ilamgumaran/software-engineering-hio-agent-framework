# Phase 1: First Unit (Weeks 4-10)

## Strategic Intent

Launch the first cognitive unit with full agent support and the harmonized sprint model. This phase produces the first real evidence of HIO's value -- or reveals where the framework needs adjustment. The comparison board makes results visible to the entire org.

---

## Timeline

| Week | Focus | Key Activities |
|------|-------|---------------|
| **Week 4** | Unit formation | Finalize unit composition, workshop outcome statement, draft working agreements |
| **Week 5-6** | First sprints | Run first 2 harmonized sprints, deploy all 6 agents, begin emergence logging |
| **Week 7-8** | Calibration | Adjust agent configurations, refine ceremonies, address friction points |
| **Week 9-10** | Evidence gathering | Compile comparison board data, prepare Phase 2 recruitment materials |

---

## Key Deliverables

| Deliverable | Definition of Done |
|-------------|-------------------|
| **Operational cognitive unit** | Unit running harmonized sprints with defined outcome |
| **All 6 agents deployed** | Each agent used at least once by the unit |
| **Working agreements** | Documented per `org/working-agreements.md` |
| **Comparison board** | Side-by-side metrics for first unit vs. legacy teams |
| **Emergence log entries** | At least 3 documented emergence events |
| **Phase 2 recruitment brief** | Evidence-based summary for the next wave of volunteers |

---

## Exit Criteria

Phase 1 is complete when:

1. The first cognitive unit has completed at least 3 harmonized sprints
2. All 6 agents are operational and integrated into the unit's workflow
3. The comparison board shows at least one metric category improving vs. baseline
4. Emergence events are being captured
5. At least 6 additional people have expressed interest in joining Phase 2

**If exit criteria are not met by Week 10:** Extend Phase 1 by 2 weeks. Investigate whether the issue is tooling, cultural resistance, or framework fit.

---

## Risks

| Risk | Mitigation |
|------|-----------|
| First unit underperforms vs. legacy teams | Expected in early sprints -- focus on trend, not absolute values |
| Agent tooling friction | Dedicate infrastructure support; treat agent issues as P1 during Phase 1 |
| Team members revert to role-based habits | HIO coach facilitates; use grip awareness exercises from `plan/04-foundational-skills.md` |

See `transformation/phase-1-first-unit.md` for full operational detail and `plan/03-implementation-guide.md` for step-by-step instructions.
