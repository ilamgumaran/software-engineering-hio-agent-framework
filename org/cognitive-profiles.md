# Cognitive Profiles

> Each team member completes a cognitive profile during Phase 0 (pioneers) or when joining a cognitive unit. Profiles are owned by the individual and reviewed quarterly.

---

## Profile Template

### [Person Name]

- **Current role:** [e.g., Senior Backend Engineer]
- **Primary functions:** [2-3 cognitive functions, e.g., Solution Architect + Builder]
- **Developing function:** [1 function actively growing into, e.g., Pattern Integrator]
- **Bandwidth expansion goal:** [Function to explore this quarter]
- **Preferred cognitive unit:** [Chosen by interest, e.g., Experiment Velocity]
- **AI comfort level:** [1-10 scale]
- **Fulfillment drivers:** [What makes work meaningful, e.g., solving hard problems, mentoring juniors]
- **Notes:** [Any context -- preferences, constraints, aspirations]
